# PRAHARI Cost Explainability Contract

**Status:** CONTRACT IMPLEMENTED; LIVE CONTRIBUTORS WITHHELD

Cost explanations must originate from a governed, admitted cost model and known-at-T fields. They may describe association only. Allowed language includes: expenditure relative to approved cost, project age, known schedule revision, remaining schedule, observed stagnation and already-approved C2 cost escalation.

The system must never state that a feature caused an overrun, blame a contractor or agency, invent an exact future final cost, change the target horizon, or derive a probability in prose. Peer comparisons require at least 30 valid peers and report the cohort size; otherwise they are withheld.

Because no C1/C2 model passed research admission, current API and assistant evidence contains a null cost probability, null cost band, no contributors and `NO_COST_MODEL_PASSED_RESEARCH_ADMISSION`. Source-backed target-review examples are not predictions and are labelled accordingly.
