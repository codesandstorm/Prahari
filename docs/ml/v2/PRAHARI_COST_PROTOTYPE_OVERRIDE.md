# PRAHARI Cost Prototype Research Override

**Governed mode:** `PROTOTYPE_RESEARCH_OVERRIDE`  
**Target validation:** `MACHINE_PROVISIONAL`  
**Production ModelRelease:** `WITHHELD`

The override permits machine-provisional target construction, temporal backtesting, statistical/ML comparison, research calibration, ensembles and clearly marked prototype payloads. It does not remove normal Data Trust, Model Release, Prediction Eligibility, provenance, abstention or Officer Decision gates.

It does not permit claims of human-validated truth, official MoSPI approval, production validation, causal explanation or certainty. It cannot set ModelRelease to RELEASED. Research cost signals cannot silently create production alerts.

Current outcome: the override enabled a reproducible experiment, but no model passed admission. Backend and LLM evidence therefore fail closed with `cost_prediction_status=WITHHELD`, nullable probability/band, empty contributors and explicit reasons. The correct final project status is partial until target adjudication and stronger temporal evidence justify a stable candidate.
