# Basic Long History V1

Version: `basic-long-history-v1`.

Ordered features: log original cost; planned duration months; project age months; expenditure-to-original-cost; observed history span months; remaining approved schedule months; cumulative approved cost revision percent; and one-month expenditure velocity.

Every value is computed as of the anchor month. Velocity requires the exact prior calendar month. Missing values remain missing for fold-local handling. Physical progress is deliberately absent because OCMS historical reports do not support it structurally. No contractor, funding-release, milestone-derived label, imputation, external event or future observation is introduced.
