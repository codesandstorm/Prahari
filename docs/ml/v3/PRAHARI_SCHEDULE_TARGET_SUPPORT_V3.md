# PRAHARI Schedule Target Support V3

After the explicit-revised-date correction, the three-month Basic cohorts contain 19,465 S1 anchors with 1,713 events and 8,390 S2 anchors with 2,743 events. Compact V2 contains 8,555 S1 anchors with 1,018 events and 4,316 S2 anchors with 1,814 events. These are machine-provisional observations, not adjudicated ground truth.

Complete future project-level coverage is required. Aggregate-only or missing months censor crossing horizons. Completed-at-T anchors, non-exact identities, missing approved dates, prior-month gaps and target-inapplicable states are excluded. Project disappearance is never treated as completion or a negative outcome.

Six-month cohorts are research-only: S1 has 10,586 anchors and 1,371 events; S2 has 4,325 anchors and 1,765 events. Neither supports a final six-month model because only S1 has one admitted fold and S2 has none.
