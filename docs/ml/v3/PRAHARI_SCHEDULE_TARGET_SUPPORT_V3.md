# PRAHARI Schedule Target Support V3

The three-month Basic cohorts contain 20,520 S1 anchors with 2,120 events and 8,952 S2 anchors with 2,900 events. Compact V2 contains 9,381 S1 anchors and 4,532 S2 anchors. These are machine-provisional observations, not adjudicated ground truth.

Complete future project-level coverage is required. Aggregate-only or missing months censor crossing horizons. Completed-at-T anchors, non-exact identities, missing approved dates, prior-month gaps and target-inapplicable states are excluded. Project disappearance is never treated as completion or a negative outcome.

Six-month cohorts are research-only: S1 has 11,571 anchors and 1,915 events; S2 has 4,931 anchors and 2,022 events. Neither supports a final six-month model because only S1 has one admitted fold and S2 has none.
