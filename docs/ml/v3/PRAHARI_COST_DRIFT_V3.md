# PRAHARI Cost Drift V3

V3 treats the pre-COVID, COVID, late-OCMS, OCMS restart, PAIMANA transition and recent PAIMANA periods as distinct temporal regimes. It reports descriptive PSI and prevalence changes for original cost, expenditure ratios, project age and target prevalence.

These diagnostics show distributional and target instability and are not causal tests. COVID years are retained rather than removed, while fold-wise results reveal whether learning from them transfers. Structural missingness—especially physical progress in older OCMS reports—is preserved; no physical-progress value is fabricated or imputed across schema eras.

The machine-readable evidence is `outputs/ml/cost_prediction_v3/drift_summary.csv`, `event_distribution_by_year.csv`, `fold_summary.csv`, and `history_window_metrics.csv`.
