# PRAHARI Schedule Lead Time V3

Lead time is computed only for a selected candidate using genuinely out-of-sample predictions and its frozen past-validation threshold. Events are grouped by canonical project and event month so repeated anchors do not inflate event counts.

No S1 or S2 candidate was admitted, so lead-time results are explicitly `NOT_EXECUTED`. This prevents descriptive model output from being presented as proven early warning.
