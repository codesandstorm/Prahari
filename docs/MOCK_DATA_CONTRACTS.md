# Mock Data Contracts

All values are local demonstration fixtures. They are designed to be replaceable by API adapters without changing page composition.

## Core objects

- Project: `id`, `name`, ministry/agency/sector, state, phase, schedule, cost, Execution Health, Data Quality and Officer Action.
- Alert: `id`, `projectId`, type, priority, reason, lifecycle status, assignee and update date.
- Review: `id`, `projectId`, type, workflow state, priority, assignee, next review and update date.
- Project detail: baseline/revised cost and dates, expenditure, progress, research preview states and officer action.
- Milestone: name, reported date, state, variance and evidence label.

Mock numbers demonstrate product states only. They must not be presented as live government records, released predictions, validated model performance, or final-cost forecasts.
