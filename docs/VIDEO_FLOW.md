# Final Video Flow

## Primary

1. Landing: allow the hero and project carousel to rotate; use Portfolio Overview and State View anchors.
2. Officer Login: sign in with the supplied local access credentials.
3. Overview: open Projects.
4. Projects: search `BHATADI`, open the dossier.
5. Project Overview: scan the four-card intelligence strip and Milestone Journey.
6. Schedule: inspect the three-month forecast and progress evidence.
7. Ask PRAHARI: ask **Why is the schedule at risk?** and show evidence, recommended attention and sources.
8. Open Alerts, then the linked Review; add a note, complete an action, choose an outcome and save the next step.

## Secondary

1. Landing: use State View and High Value Projects.
2. Login and open Analytics.
3. Hover/click map states, inspect sector Execution Health, schedule/cost distributions and BHATADI peer comparison.

Before recording, use Settings → Reset Experience to restore the deterministic starting state.
