# PRAHARI Implementation Watch V1 Limitations

The current 48,326-row historical artifact does not contain structured scheduled physical progress, compatible scheduled/actual financial percentages, milestone records, land, ROW, clearances, tenders or funding. `milestones_raw` is retained source text and is not treated as a typed milestone table. Consequently, present historical Watch coverage is strongest for reporting/provenance, physical-progress stagnation, and existing calendar-safe schedule-pressure calculations.

Watch states describe detected evidence, not future probability, root cause, blame, contractor performance, fraud, corruption or administrative culpability. A threshold is a versioned review rule rather than an official risk threshold. `CLEAR` means evaluated signals did not fire; it never guarantees project health.

The official CUF document is dated 3 September 2024. Period-bound fields such as Total Capital Outlay for the NIP period ending FY2024-25 require contract revision before reuse in a later reporting regime. Ministry-specific start-date and milestone subcategory semantics require governance.

Schedule S1/S2 and Cost C1/C2 remain machine-provisional research with no admitted operational model. Both probabilities remain withheld. No CUF experiment was run and no prediction artifact was created by this work.
