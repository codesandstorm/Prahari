# PRAHARI Review State Machine V1

Policy version: `officer-review-v1.0` in `config/officer_review_policy_v1.json`.

## Alert transitions

| From | Allowed next states |
|---|---|
| NEW | ACKNOWLEDGED, IN_REVIEW, PERSISTENT, ESCALATED, RESOLVED, DISMISSED |
| ACKNOWLEDGED | IN_REVIEW, MONITORING, PERSISTENT, ESCALATED, RESOLVED, DISMISSED |
| IN_REVIEW | MONITORING, PERSISTENT, ESCALATED, RESOLVED, DISMISSED |
| MONITORING | IN_REVIEW, PERSISTENT, ESCALATED, RESOLVED, DISMISSED |
| PERSISTENT | IN_REVIEW, MONITORING, ESCALATED, RESOLVED, DISMISSED |
| ESCALATED | IN_REVIEW, MONITORING, RESOLVED, DISMISSED |
| RESOLVED | REOPENED |
| DISMISSED | REOPENED |
| REOPENED | ACKNOWLEDGED, IN_REVIEW, MONITORING, PERSISTENT, ESCALATED, RESOLVED, DISMISSED |

## Review transitions

| From | Allowed next states |
|---|---|
| NOT_STARTED | IN_PROGRESS, CLOSED_NO_ACTION |
| IN_PROGRESS | MONITORING, ACTION_REQUIRED, COMPLETE, CLOSED_NO_ACTION |
| MONITORING | IN_PROGRESS, ACTION_REQUIRED, COMPLETE, CLOSED_NO_ACTION |
| ACTION_REQUIRED | IN_PROGRESS, MONITORING, COMPLETE, CLOSED_NO_ACTION |
| COMPLETE | none; an alert reopen resets the review |
| CLOSED_NO_ACTION | none; an alert reopen resets the review |

Illegal transitions fail with a bounded contract error and roll back the transaction.
