# Screen Inventory

The delivered inventory contains 20 routed screens plus two global assistant surfaces, covering all 22 requested inventory items:

- Public: landing and officer login.
- Portfolio: overview, projects, attention queue, monitoring and analytics.
- Intelligence: project overview, schedule, cost, Execution Health and Milestone Journey.
- Workflow: alert list, alert detail, review list and review detail.
- Support: reports, personal workspace, notifications and settings.
- Global: Ask PRAHARI launcher and contextual drawer.

Every authenticated screen uses the same MoSPI/PAIMANA header, sidebar and Ask PRAHARI pattern. Project intelligence maintains one tab system and one evidence boundary. Tables support horizontal overflow at narrow widths.
