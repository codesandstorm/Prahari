# Design System

The interface uses a single PAIMANA officer system across public, authentication, portfolio, project, alert, and review surfaces.

## Foundation

- Deep navy: identity, navigation and primary text.
- Cyan/blue: links, active states, structured information and maps.
- Amber: watch states and officer attention.
- Red: high concern or required action, never decorative urgency.
- Green: verified, complete or healthy states.
- White and pale blue: official, high-legibility surfaces.

Typography uses Inter/Segoe UI fallbacks with a 16px document base. Cards use restrained radii, 1px borders, shallow shadows and consistent section headers. Status is never communicated by color alone; every state includes text.

## Locked language

- Execution Health
- Milestone Journey
- Data Quality
- Forecast
- Officer Action
- Similar Project Comparison

## Responsive rules

Desktop preserves the full header, sidebar and right-side context. Tablet stacks right rails below core work. Mobile collapses sidebar labels, stacks grids and makes wide tables and journeys horizontally scrollable.
