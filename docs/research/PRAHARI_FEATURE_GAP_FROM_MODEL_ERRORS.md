# Feature Gaps Revealed by Model Errors

| Model error pattern | Missing observable signal | Candidate CUF field | Earliest knowable time | Burden | Target |
|---|---|---|---|---|---|
| apparently healthy then deteriorates | milestone slippage | planned/revised/actual milestone dates | first missed milestone | medium | S1/S2 |
| progress slows without visible reason | unavailable work front | land available for work percentage | monthly | medium | S1/S2 |
| sudden slowdown | contractor disruption | package contractor status and stoppage event | event time | medium | all |
| schedule changes after administrative delay | pending clearance age | clearance register with dates/status | application and each update | medium | S1/S2 |
| spending/progress disconnect ambiguous | funding versus payment timing | allocation/release/utilisation dates and values | each release | high | all |
| warning but no event | recovery action absent | approved recovery plan and action log | intervention time | low | false-positive adjudication |
| abrupt unexplained event | verified disruption | issue/event register with first-known timestamp | event time | low | event-conditioned reassessment |
| false alert after data correction | reporting revision | correction reason and corrected-at timestamp | correction time | low | reliability |

These recommendations arise from what current evidence cannot distinguish. They are hypotheses for prospective collection, not claims that a missing mechanism caused any sampled project outcome.
