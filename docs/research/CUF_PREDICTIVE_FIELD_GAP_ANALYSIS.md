# CUF Predictive Field Gap Analysis

| Predictive concept | Classification | Current evidence | Consequence |
|---|---|---|---|
| project scale and approved plan | CURRENT_CUF_SUFFICIENT | cost and completion dates appear publicly | usable with point-in-time guardrails |
| current expenditure/progress | CURRENT_CUF_PARTIAL | progress absent in historical OCMS; expenditure present | schema-aware modelling |
| approved revision history | CURRENT_CUF_PARTIAL | monthly snapshots expose changes but not approval/reason metadata | outcome adjudication required |
| anticipated date/cost | NEEDS_VERIFICATION | historical Flash fields; modern processed availability absent | do not rely on V1 model |
| milestone slippage | NEEDS_VERIFICATION | official concept-note annexure unavailable | Model C contract only |
| land and clearances | PROPOSED_NEW_CUF_FIELD | absent from current dataset | high-value leading indicators |
| contractor continuity | PROPOSED_NEW_CUF_FIELD | agency is not contractor | essential for exit/stoppage scenario |
| project-level funding release | PROPOSED_NEW_CUF_FIELD | expenditure is not allocation/release | distinguish funding constraint |
| verified weather/disaster | BETTER_AS_EXTERNAL_DATA | timestamped external event | post-event reassessment only |
| market price shocks | BETTER_AS_EXTERNAL_DATA | project exposure is not captured | evaluate selectively, not blanket macro series |

Current Flash data supports a narrow schedule-revision research target. It cannot observe why deterioration occurred, package-level contractor state, land availability, clearance ageing, resource shortages, funding release delays, or unexpected events.

Additional CUF recommendations must be evaluated prospectively. Model C has no empirical result in this repository because those inputs are not presently available and timestampable.
