# PRAHARI Review Queue Policy V1

**Owner:** PRAHARI governance team
**Status:** APPROVED WITH LIMITATIONS
**Document type:** REFERENCE

States are `REVIEW_RECOMMENDED`, `DATA_VERIFICATION_REQUIRED`, `MONITOR`, `NO_REVIEW_SIGNAL` and `PREDICTION_WITHHELD`.

Data defects that an officer can investigate route to data verification. Scientific release pending by itself routes to prediction withheld and does not imply bad project data. Completed projects normally produce no review signal. A future released `HIGH` signal can recommend review only with available prediction, acceptable reliability and usable Data Trust.

Administrative priority is null in V1 because no defensible high/medium/low ordering policy has been approved. The historical 90th-percentile threshold represents approximate review capacity, not 90% failure probability, and remains dormant until model refreeze.
