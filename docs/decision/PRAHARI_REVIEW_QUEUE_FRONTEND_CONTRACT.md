# PRAHARI Review Queue Frontend Contract

**Owner:** PRAHARI frontend and backend team
**Status:** APPROVED WITH LIMITATIONS
**Document type:** REFERENCE

Each entry exposes project identity, as-of month, target when applicable, review state, nullable priority, prediction status, reliability, intrinsic Data Trust summary, last valid update, deterministic reason codes, recommended action, policy versions and a provenance link when supported. The frontend performs no formulas.

Safe actions include “Review latest project update”, “Verify schedule revision”, “Request updated project status”, “Verify missing reporting period” and “Review project due to elevated predictive signal”. Blame, certainty, fraud and punishment language is forbidden.

Synthetic future-risk examples used in tests must never appear as production queue data.
