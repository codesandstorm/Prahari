# PRAHARI Model Release Governance

**Owner:** PRAHARI scientific review team
**Status:** ACTIVE
**Document type:** REFERENCE

Intrinsic Data Trust answers whether project evidence is usable. `ModelReleaseStatus` separately answers whether target validation, calibration and the model are approved. `PredictionEligibilityResult` combines both with completion, target and artifact gates.

Current release reasons are `HUMAN_TARGET_VALIDATION_PENDING`, `CALIBRATION_NOT_CONFIRMED` and `MODEL_NOT_RELEASED`. They withhold prediction exposure but never downgrade intrinsic Data Trust.

The thirteen-month rule remains `PROVISIONAL_VALIDATED_MINIMUM_HISTORY_V1`. It is a versioned prototype eligibility rule based on current evidence, not a universal infrastructure-project requirement.
