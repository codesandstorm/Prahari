# PRAHARI Unified Project Intelligence V1

**Owner:** PRAHARI Backend
**Status:** COMPLETE
**Last Updated:** 2026-09-13

`unified-project-intelligence-v1.0` is the canonical composition payload for project pages, review queues, dashboards, Ask PRAHARI, alerts, and future reporting. It composes existing subsystem results; it does not recalculate Implementation Watch, Data Trust, or Officer Decision.

Sections are identity, current state, schedule intelligence, cost intelligence, Implementation Watch, Data Trust, reliability, peer benchmark, attention trend, Officer Decision, alerts, evidence, assistant context, provenance, mode, and data origin. No overall risk score exists.

Schedule is `WITHHELD` with `SCHEDULE_PREDICTION_FINAL_V3_PARTIAL` / `INSUFFICIENT_TEMPORAL_VALIDATION`. Cost is `WITHHELD` with `COST_PREDICTION_V3_PARTIAL` / `NO_COST_MODEL_ADMITTED`. Both probabilities and risk bands are null. Deterministic pressure evidence remains separate and useful.

Attention trend uses Watch history and, when available, Data Trust change—not invented historical predictions. Recommended actions are bounded to review, verify, monitor, and inspect evidence. Agency is explicitly not relabelled as contractor.
