# PRAHARI Data Trust Limitations

**Owner:** PRAHARI data and ML team
**Status:** ACTIVE
**Document type:** REFERENCE

Data Trust measures whether evidence is sufficient and traceable for governed processing. It does not measure project performance, safety, fraud, causality or overrun risk.

The thirteen-month rule is provisional. Historical schemas omit fields available in later reports. A registered source does not guarantee administrative correctness. Self-reported values can be internally consistent yet wrong. Technical warnings require officer review and must not be automatically converted into false data.

Backend V1 snapshots retain fewer raw fields than the canonical dataset. Backend trust evaluation therefore fails closed when full Compact V2 evidence cannot be reconstructed. Human adjudication and independent calibration confirmation remain mandatory before operational probabilities are released.
